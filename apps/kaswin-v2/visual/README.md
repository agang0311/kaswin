# 页面视觉与呈现

| 文件 | 可修改范围 |
|---|---|
| `index.template.html` | 页面骨架、meta、导航与按钮容器；保留控制器依赖的ID和data属性 |
| `styles.css` | 布局、主题、尺寸、颜色、响应式；不能以隐藏风险提示改变授权边界 |
| `icons.mjs` | 从原控制器原样分出的SVG图标数据与渲染函数 |
| `view.mjs` | 状态/费用/动作说明的只读展示，不授权动作或释放资金 |
| `i18n.mjs` | 纯文字翻译、浏览器本地时区格式、语言切换 |
| `messages-en.mjs` | 审阅过的英文目录和动态插值占位符 |

视觉层不保存交易，不签名、不提交、不定义合约经济参数。表单value、URL、金额、data属性、journal、动作枚举不翻译；外部诊断不重新解释成HTML。语言切换不重新渲染业务页面，不重置批准/报价时限。浏览器Intl负责时区/夏令时，DAA不是Unix时间。

`app.mjs`仍负责动态DOM模板与交互绑定，改页面结构需检查该控制器和浏览器测试；此目录分离不等于所有HTML字符串已经组件化。
