单 HTML 必须可在允许网络完成无许可创建、购买、满额封盘、可验证公平开奖/派奖、未满退款和空轮回收；能验证链上状态、历史、acceptance/reorg 与资金记录。完整代码/产物/设计保留。核心协议验证不通过时不能开放真实资金入口。

## 当前有界交付：离线协议工作台

这不是最终链上产品，也不是用户对范围降级的批准。它是保留的中间产物：自包含 HTML，可直接打开，提供规则草案填写、精确金额预览、严格 JSON 导入导出、A 型状态和风险说明。

- 没有 RPC、钱包、签名、密钥、广播或伪造链上历史。
- 不计算模拟中奖者，不把本地文件当成链上证明。
- 购买/创建链上轮次保持不可用，持续显示未部署标记。
- 本地草案范围不冒充已验证的共识/产品上限。
- 仅验证金额/输入边界、导入与交付自包含性，不新增装饰性测试。

该中间产物用于形成可检查的真实文件，同时协议研究继续。不得把交付工作台描述为已经完成公平链上抽奖。

## 暂不选定完整生产算法的理由

历史证明恢复需要真实脚本能力、上下文验证、证明取数、恶意进度防护与费用证明；矿工偏置尚未给出可接受量化上界。有限储备和任何人自愿执行并不推出总能无成本恢复。不能凭哈希递推公式编造完整安全性。
