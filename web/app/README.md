# 应用交互

`app.mjs` 是浏览器入口，负责页面路由、钱包连接、轮次列表/详情、操作报价与逐笔批准。`network.mjs` 选择网络配置，`catalog.mjs` 提供目录入口。

交易计划和执行使用 `scripts/round/`，节点与接受数据使用 `scripts/chain/`，状态追踪使用 `scripts/tracking/`。展示逻辑放在 `web/ui/`，协议规则放在 `scripts/core/`。

切换网络会断开钱包并重建运行时；两个网络的缓存、交易记录和输入占用分开保存。切换不能改变编译模式提供的交易权限，也不能清除未知交易占用。

页面必须区分缓存、索引线索和节点核验结果。未知或等待状态不当作成功；只有实际接受核验才能推进相关记录。
